# 前端简历高分项目 & 技术栈识别清单

> 适用：初级 ~ 高级前端简历技术初筛  
> 使用方式：对照清单打分，≥70 分建议进入面试

---

## 1. 技术栈识别（权重 30%）

### 1.1 基础必选项

| 技术点 | 初级期望 | 中级期望 | 高级期望 |
|--------|----------|----------|----------|
| JavaScript / TypeScript | ES6+ 熟练 | TS 大型项目 | TS 类型体操 + 规范制定 |
| 框架 | React 或 Vue 二选一 | React 18 生态精通 | 框架原理 + 架构选型 |
| CSS | Flex/Grid 布局 | 响应式 + 预处理 | 设计系统 + 性能 |
| 构建工具 | 了解 Vite/Webpack | 配置优化 | 工程体系设计 |
| Git | 基本协作 | 分支策略 | 团队规范 |

### 1.2 加分技术栈

- **客服/IM 场景：** WebSocket、SSE、虚拟列表、消息去重
- **电商场景：** 大促性能、骨架屏、懒加载、CDN 策略
- **工程化：** Monorepo、CI/CD、单元测试（Jest/Vitest）、E2E
- **性能：** Lighthouse 优化、Bundle 分析、SSR/SSG 经验

---

## 2. 高分项目特征（权重 40%）

### 2.1 项目描述质量

**高分信号：**

- 明确 **个人职责**（「我负责 XX 模块」而非「我们做了」）
- 有 **量化成果**：首屏从 3s 降至 1.2s、列表支持 10 万条流畅滚动
- 技术难点具体：虚拟滚动实现、WebSocket 重连策略、状态管理拆分
- 项目 **可验证**：线上链接、GitHub、演示视频

**低分信号：**

- 仅罗列技术名词，无业务场景
- 项目时间与工作经历不匹配
- 多个项目技术栈完全一致、描述雷同（模板简历）

### 2.2 客服 / 电商方向优质项目

| 项目类型 | 识别要点 |
|----------|----------|
| 客服工作台 | 会话列表、多 tab、实时消息、工单联动 |
| 商家后台 | 复杂表单、权限菜单、数据大屏 |
| 电商前台 | 商品详情、购物车、大促会场 |
| 组件库 | 组件数量、文档站、主题定制、发布流程 |

---

## 3. 工作经历一致性（权重 20%）

- 跳槽频率：3 年 3 跳以上需谨慎
- 职级成长曲线是否合理
- 空窗期 >6 个月须备注
- 公司规模与项目复杂度是否匹配

---

## 4. 软实力信号（权重 10%）

- 技术博客、开源贡献、大会分享
- Code Review、带人、规范制定经历
- 英文文档阅读能力（阅读官方文档）

---

| 维度 | 满分 | 得分 |
|------|------|------|
