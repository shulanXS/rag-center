# Agent 开发简历核心项目识别（RAG、向量检索、多智能体）

> 适用：初级 ~ 高级 AI Agent / RAG 工程师简历初筛

---

## 1. 技术栈识别

| 层级 | 期望技术点 |
|------|------------|
| 基础 | Python、FastAPI、HTTP API、Docker 基础 |
| RAG | Embedding、向量库、分块策略、Hybrid Search、Rerank |
| Agent | LangChain / LangGraph、Tool Calling、多 Agent 路由 |
| 评估 | 测试集、Recall@K、Bad Case 分析、A/B 测试 |
| 工程 | 多租户、鉴权、日志、成本监控 |

---

## 2. 优质 RAG 项目信号

**高分描述应包含：**

- 数据规模：文档量、chunk 数量、知识库更新频率
- 检索方案：纯向量 vs Hybrid、是否 Rerank、用的什么模型
- 效果指标：准确率 / 满意度 / 人工转接率变化
- 难点：幻觉治理、长文档分块、多租户隔离、延迟优化
- 个人贡献：「我负责召回链路优化，Recall@5 从 62% 提升到 78%」

**低分描述：**

- 「用 LangChain 做了一个聊天机器人」无业务场景
- 仅调用 OpenAI API 做 Prompt，无检索链路
- 无量化效果、无线上运行

---

## 3. 多智能体项目识别

| 要素 | 识别问题 |
|------|----------|
| 编排框架 | LangGraph？自研状态机？ |
| Agent 分工 | 意图识别、检索、工具调用、人工转接如何拆分？ |
| 可观测 | 是否记录每步 trace？如何调试？ |
| 失败处理 | Agent 死循环、工具调用失败怎么办？ |

---

## 4. 业务场景匹配（客服方向）

优先识别以下场景经验：

- 智能客服问答 / 知识库助手
- 工单自动创建 / 意图路由
- 文档上传解析与索引 pipeline
- 人机协同（AI 草稿 + 人工审核）

---

## 5. 快速打分

| 维度 | 满分 |
|------|------|
| RAG 链路完整度 | 35 |
| Agent 编排经验 | 25 |
| 效果与工程化 | 25 |
| 业务匹配度 | 15 |

≥70 分建议面试。AI 岗位市场变化快，**项目真实度** 优先于年限。
