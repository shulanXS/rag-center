# 转行后端开发候选人筛选评判标准

> 适用：培训班转行、其他岗位转后端、自学转行

---

## 1. 基本门槛

- 掌握一门后端语言（Java / Go / Python）基础语法与 OOP
- 能写 CRUD API，理解 HTTP、JSON、RESTful
- 了解 MySQL 基本 SQL 与索引概念
- 有 **至少 1 个可演示的后端项目**（含数据库）

---

## 2. 加分项

- 原岗位有技术相邻经验：运维、测试开发、DBA、嵌入式
- 有计算机基础：数据结构、网络、操作系统课程成绩或自学证明
- GitHub 有持续提交的后端项目
- 完成过实习或外包真实交付

---

## 3. 减分项

- 简历项目全部为培训营统一模板
- 只会跟着视频敲，无法解释代码含义
- 对数据库事务、并发无基本认知
- 薪资要求对标 3 年经验后端

---

## 4. 评判流程

1. **笔试（必选）：** 基础语法 + 简单算法 + SQL 题
2. **作品 Review：** 检查项目结构、分层、异常处理
3. **面试：** 深挖一个项目的数据流与表设计
4. **HR：** 转行动机与稳定性

---

## 5. 录用标准

| 结果 | 条件 |
|------|------|
| 录用 P4 | 笔试 ≥60 分 + 项目达标 + 动机合理 |
| 待定 | 笔试边缘，安排加试 |
| 不录用 | 笔试 <50 或项目无法讲解 |

---

## 6. 培养计划

入职后 3 个月须完成：独立开发简单 API、参与 Code Review、完成一次线上值班跟班。
