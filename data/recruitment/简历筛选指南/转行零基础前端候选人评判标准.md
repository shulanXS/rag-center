# 转行零基础前端候选人评判标准

> 适用：非计算机专业、培训班转行、自学转行  
> 原则：看潜力与可培养性，不以年限一刀切

---

## 1. 适合转行的信号

- **6 个月以上** 系统学习记录（课程 + 作品集 + 笔记）
- 有 **2 个以上完整可演示项目**（非跟着教程敲的 Todo）
- 简历能讲清 **为什么转行** 且逻辑自洽
- 对前端基础有正确认知（浏览器、HTTP、异步）
- 学习能力强：有持续输出（博客、GitHub 提交记录）

---

## 2. 不建议推进的信号

- 培训营包装项目，_DESCRIPTION 与网络模板一致
- 仅完成培训班作业，无自主扩展
- 对基础问题完全答不上（如 var/let/const、闭包）
- 薪资预期远超初级带宽且无作品支撑
- 频繁换培训方向（前端→测试→运维）

---

## 3. 评判维度与权重

| 维度 | 权重 | 考察方式 |
|------|------|----------|
| 基础扎实度 | 35% | 笔试 + 电话初筛 |
| 作品质量 | 35% | 作品演示 + 代码 Review |
| 学习能力 | 20% | 面试追问学习路径 |
| 稳定性与动机 | 10% | HR 沟通 |

---

## 4. 作品最低标准（初级转行）

至少满足 **3 项**：

1. 响应式布局，移动端适配正常
2. 调用过真实公开 API（非 mock 死数据）
3. 使用 React 或 Vue 组件化开发
4. 有 Git 仓库，commit 记录真实
5. 处理了加载态、错误态、空状态

---

## 5. 录用建议

| 综合表现 | 建议 |
|----------|------|
| 基础 + 作品均达标 | 可录用 P4，3 个月导师制 |
| 基础薄弱但作品亮眼 | 加长试用期，降薪带宽下限 |
| 仅培训班模板项目 | 不建议录用 |
| 有相邻经验（UI 设计、测试） | 可适当加分 |

---

## 6. 培养预期

转行初级入职后 **3 个月内** 须达到：

- 独立完成简单页面开发
- 能对接后端 API 并联调
- 遵守团队 Git 与 Code Review 规范

达不到则启动试用期评估流程。
