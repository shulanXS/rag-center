# 候选人背调通用流程与标准问题清单

> 适用范围：P5 及以上、核心系统权限岗、所有高级岗  
> 版本：v1.0 | 归口：人力资源部

---

## 1. 背调触发条件

满足以下 **任一** 条件，须在发放 Offer 前完成背调：

- 目标职级 P6 及以上
- 岗位涉及支付、用户隐私、核心算法、生产环境 root 权限
- 候选人工作经历中有 **2 年以内** 的任职（重点核实最近一段）
- 面试评价中存在「项目真实性待核实」「离职原因存疑」等备注
- 部门负责人或 HR 特批要求

校招应届生：仅做学历验证 + 实习经历核实（如有）。

---

## 2. 背调流程

```
候选人授权 → HR 发放《背调授权书》→ 候选人签字
    → 选择背调方式（公司自查 / 第三方机构）
    → 执行核实（3~5 工作日）
    → 出具《背调报告》→ HR + 用人部门负责人审阅
    → 绿灯放行 / 黄灯合议 / 红灯终止 Offer
```

**候选人知情权：** 须事先告知背调范围，取得书面授权。未经授权不得开展背调。

---

## 3. 背调核实项

| 核实项 | 方式 | 必备 |
|--------|------|------|
| 身份信息 | 身份证核对 | 是 |
| 学历学位 | 学信网 / 毕业证原件 | 是 |
| 工作经历 | 前雇主 HR 或直属上级 | 是（最近 1~2 段） |
| 离职原因 | 前雇主 HR（客观核实） | 是 |
| 竞业限制 | 候选人声明 + 前雇主确认 | 视岗位 |
| 刑事/诉讼 | 第三方背调 / 候选人声明 | P6+ 建议 |
| 薪资流水 | 候选人提供（可选） | 薪酬争议时 |

---

## 4. 标准核实问题清单（致前雇主）

> HR 或第三方背调员使用，语气客观中立，不涉及歧视性内容。

### 4.1 致前雇主 HR

1. 请确认 [姓名] 是否于 [起始日期] 至 [结束日期] 在贵司任职，职位为 [职位名称]？
2. 其离职性质为：主动离职 / 协商离职 / 辞退 / 其他（请说明）？
3. 是否存在未解除的劳动纠纷或竞业限制协议？
4. 贵司是否愿意再次雇佣该员工？（是 / 否 / 不便透露）

### 4.2 致前直属上级（需候选人提供联系方式并授权）

1. 请确认您与 [姓名] 的共事时间及汇报关系。
2. 其在团队中的主要职责是什么？（核实与简历一致性）
3. 技术能力 / 工作表现评价：优秀 / 良好 / 一般 / 较差 / 不便评价
4. 团队协作与沟通能力评价。
5. 是否存在违纪、重大工作失误或与客户 / 同事的严重冲突？
6. 如有机会，您是否愿意再次与其共事？

**注意：** 前雇主拒绝配合时，须记录尝试次数与时间，改由候选人补充证明材料（劳动合同、社保记录、工资流水等）。

---

## 5. 背调结论分级

| 结论 | 含义 | 处理 |
|------|------|------|
| 绿灯 | 全部核实一致，无负面记录 | 正常发放 Offer |
| 黄灯 | 部分信息无法核实，或存在非原则性差异 | HR + 部门负责人合议，可要求候选人补充说明 |
| 红灯 | 学历造假、工作经历虚构、严重违纪、竞业冲突 | **终止录用**，通知候选人（话术见模板库） |

---

## 6. 保密与存档

- 背调报告仅限 HR、用人部门负责人、审批链相关人员查阅。
- 报告保存至员工入职档案，保存期限按劳动法及公司档案规定执行。
- 禁止将背调负面细节透露给无关同事。
