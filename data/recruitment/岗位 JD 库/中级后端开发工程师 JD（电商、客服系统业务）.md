## 岗位职责

1. **独立负责** 客服会话、工单流转、订单售后、知识库等核心服务的设计与开发。
2. 参与 **高并发场景** 优化：缓存策略、异步解耦、数据库读写分离、限流降级。
3. 保障服务 **稳定性**：完善监控告警、日志链路、故障复盘与预案。
4. 参与微服务拆分、API 网关、消息队列等基础设施的使用与改进。
5. 指导初级工程师，参与技术方案评审与 Code Review。

---

## 任职要求

### 硬性条件

- 本科及以上，**3 年以上** 后端开发经验。
- 精通 **Java / Go** 之一及对应 Web 框架（Spring Boot / Gin 等）。
- 熟练使用 MySQL，有 SQL 优化与表设计经验。
- 熟悉 **Redis、消息队列（Kafka/RocketMQ）** 的典型使用场景。
- 有 **电商、客服、工单、IM** 相关业务系统经验。

### 优先条件

- 有分布式事务、分库分表、搜索引擎（ES）实战经验。
- 熟悉 Docker、K8s 基础，有 CI/CD 实践。
- 有线上故障排查与性能调优案例。
- 了解 DDD、领域建模。
