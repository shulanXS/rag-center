## 岗位职责

1. 在导师指导下参与客服工单、订单查询、消息推送等 **后端 API** 开发与维护。
2. 编写符合规范的 RESTful 接口，完成单元测试与接口文档（Swagger）。
3. 参与数据库表设计、SQL 优化等基础工作。
4. 修复线上 Bug，参与值班与问题排查（有 senior 带队）。
5. 学习微服务、消息队列、缓存等中间件的基础使用。

---

## 任职要求

### 硬性条件

- 2025 / 2026 届本科及以上，计算机相关专业。
- 掌握 **Java / Go / Python** 至少一门语言。
- 熟悉 MySQL 基础 SQL，了解索引、事务概念。
- 了解 HTTP、JSON、Git 基本操作。
- 逻辑清晰，学习能力强，有团队合作意识。

### 优先条件

- 有实习或课程项目涉及后端 API 开发。
- 了解 Redis、Kafka / RabbitMQ 基础概念。
- 有算法基础（LeetCode 中等题水平）。
- 对电商、客服业务有兴趣。

Java 17 / Spring Boot · MySQL · Redis · Kafka · Docker 基础
