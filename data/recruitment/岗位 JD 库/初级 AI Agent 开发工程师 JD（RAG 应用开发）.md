## 岗位职责

1. 参与 **客服智能问答、知识库检索** 等 RAG 应用的开发与迭代。
2. 实现文档解析、分块、向量化、检索召回、Prompt 组装等 pipeline 模块。
3. 对接 OpenAI / 国产大模型 API，完成基础 Agent 对话流程开发。
4. 参与 RAG 效果评估：构建测试集、记录 bad case、协助优化召回策略。
5. 编写技术文档，参与 Code Review 与单元测试。

---

## 任职要求

### 硬性条件

- 本科及以上，计算机、人工智能或相关专业。
- 掌握 **Python**，熟悉 FastAPI / Flask 等 Web 框架基础。
- 了解 **大模型 API 调用**、Prompt Engineering 基础概念。
- 了解 **向量数据库**（pgvector、Milvus、Elasticsearch 等）基础原理。
- 有 RAG、问答系统、NLP 相关 **项目或课程实践** 经验。

### 优先条件

- 有 LangChain / LlamaIndex 使用经验。
- 了解 Hybrid Search（向量 + BM25）、Rerank 流程。
- 有客服、知识库、文档问答业务场景经验。
- 熟悉 Docker 基础部署。
