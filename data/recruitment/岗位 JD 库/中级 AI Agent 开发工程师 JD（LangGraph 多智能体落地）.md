## 岗位职责

1. **独立负责** 客服场景多智能体系统设计与开发：意图识别、路由、工单创建、知识检索、人工转接等 Agent 协作。
2. 基于 **LangGraph / LangChain** 构建可观测、可调试、可回放的 Agent 工作流。
3. 优化 RAG 全链路：分块策略、Hybrid Search、Rerank、上下文压缩与幻觉治理。
4. 建设 Agent 评估体系：自动化评测、A/B 测试、线上效果监控与成本分析。
5. 与产品、后端、前端协作，推动 AI 能力产品化落地。

## 任职要求

### 硬性条件

- 本科及以上，**3 年以上** 开发经验，其中 **1 年以上** LLM 应用开发经验。
- 精通 **Python**，熟悉 FastAPI 及服务化部署。
- 熟练使用 **LangChain / LangGraph**，有多 Agent 编排实战经验。
- 深入理解 **RAG 架构**：Embedding、向量检索、重排序、评估指标（Recall、MRR 等）。
- 有 **客服、知识库、智能问答** 等 ToB 落地项目经验。

### 优先条件

- 有工具调用（Function Calling）、MCP、结构化输出实践经验。
- 熟悉模型微调（LoRA）、Prompt 版本管理与灰度发布。
- 有 Elasticsearch IK 分词、pgvector 等混合检索调优经验。
- 了解多租户、API Key 鉴权等企业级 AI 中台需求。
