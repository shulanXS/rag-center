## 岗位职责

1. 在导师指导下参与电商客服工作台、商家后台等 Web 前端功能开发与维护。
2. 根据 UI 稿完成页面还原，对接后端 RESTful API，处理常见联调问题。
3. 编写基础单元测试，参与 Code Review，学习团队 Git 分支规范。
4. 修复 Jira 分配的 Bug，参与日常迭代与上线支持。
5. 学习并实践 React 技术栈及团队前端工程化工具链。

---

## 任职要求

### 硬性条件

- 2025 / 2026 届本科及以上，计算机、软件工程或相关专业。
- 熟悉 HTML5、CSS3、JavaScript（ES6+）基础。
- 了解 React 或 Vue 至少一种框架的基本用法。
- 了解 HTTP、浏览器调试工具使用。
- 可全职实习 **3 个月以上**，有转正机会。

### 优先条件

- 有个人项目、课程设计或开源贡献可展示。
- 了解 TypeScript、Webpack / Vite 基础配置。
- 有电商、客服、后台管理系统相关实习经历。
- 校招竞赛（ACM、前端挑战赛）获奖经历。
