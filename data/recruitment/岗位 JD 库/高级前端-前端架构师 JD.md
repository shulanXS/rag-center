# 高级前端 / 前端架构师 JD

## 岗位信息

| 项目 | 内容 |
|------|------|
| 岗位名称 | 高级前端工程师 / 前端架构师 |
| 所属部门 | 电商客服产品部 / 技术中台 |
| 职级 | P7~P8 |
| 工作年限 | 7 年以上 |
| 工作地点 | 【城市】 |

---

## 岗位职责

1. 主导 **客服与电商 B 端前端架构** 演进：微前端、模块联邦、低代码、跨端方案选型与落地。
2. 制定前端 **工程标准**：目录规范、性能预算、安全规范、发布与灰度策略。
3. 解决跨团队技术难题：极致性能优化、复杂状态治理、大规模组件库设计。
4. 参与技术招聘、面试官培养，推动团队技术梯队建设。
5. 与产品、后端架构师对齐，参与公司级技术规划。

---

## 任职要求

### 硬性条件

- 本科及以上，**7 年以上** 前端经验，其中 **3 年以上** 架构或 Tech Lead 经历。
- 精通 React 生态及现代前端工程化全链路。
- 有 **百万级 DAU** 或 **复杂 B 端平台** 架构设计与落地经验。
- 能独立输出架构文档，推动多团队落地。
- 优秀的技术判断力、沟通与影响力。

### 优先条件

- 有电商、客服、SaaS 多租户前端架构经验。
- 熟悉 Node.js 中间层、SSR/SSG、边缘渲染。
- 有开源项目维护或技术大会分享经历。
- 了解 AI 辅助研发工具链在前端团队的落地。

---

## 我们看重

- 架构决策的 **业务 ROI**，而非为技术而技术
- 能带团队 **降本增效** 的实战经验
- 对前端稳定性、可观测性、安全性的体系化思考
