# 员工身份与岗位职级认定标准

> 适用范围：集团全体员工及经批准纳入统一差旅管理的外部人员  
> 版本：v1.4 | 生效日期：2025-03-01  
> 归口部门：人力资源中心

---

## 1. 人员身份分类

| 身份 | 定义 | 差旅基础资格 |
|------|------|--------------|
| 正式员工 | 已通过试用期并建立正式劳动关系 | 按岗位职级认定 |
| 试用期员工 | 已入职但尚未转正 | 按岗位职级认定，审批要求从严 |
| 实习生 | 签署实习协议的在校人员 | 统一按 T0 执行 |
| 劳务派遣人员 | 与派遣机构建立劳动关系 | 合同有约定时按约定，否则按 T1 |
| 外包人员 | 由供应商派驻、费用由项目承担 | 原则上不使用员工差旅标准 |
| 外部顾问 | 按顾问合同提供专业服务 | 合同有约定时按约定，否则按 T2 |

人员身份只决定资格边界，不直接等同于岗位职级。正式员工和试用期员工仍需查询人事系统中的生效职级。

## 2. 专业序列岗位职级

| 常用岗位名称 | 标准职级 | 说明 |
|--------------|----------|------|
| 助理工程师、运营助理、产品助理 | P3 | 在指导下完成明确任务 |
| 工程师、产品经理、运营专员 | P4 | 独立负责常规模块 |
| 高级工程师、高级产品经理、高级运营经理 | P5 | 独立负责复杂模块或小型项目 |
| 资深工程师、产品专家、运营专家 | P6 | 负责核心领域或跨团队项目 |
| 技术专家、资深产品专家、业务专家 | P7 | 负责关键方向和组织级项目 |
| 高级技术专家、首席架构师、首席产品专家 | P8 | 负责公司级平台或战略项目 |
| 研究员、首席科学家 | P9 | 公司级专业带头人 |

岗位名称中出现“高级”不代表必然为 P5，“资深”也不代表必然为 P6；存在冲突时，以人事系统的生效职级为准。

## 3. 管理序列岗位职级

| 管理岗位 | 标准职级 |
|----------|----------|
| 主管、团队负责人 | M1 |
| 部门经理、研发经理、产品负责人 | M2 |
| 部门总监、中心负责人 | M3 |
| 事业部副总裁、事业群负责人 | M4 |
| 集团高级副总裁及以上 | M5 |

兼任管理岗位的员工，以当前生效的管理职级与专业职级中较高对应档执行，但不得重复享受权益。

## 4. 职级认定规则

1. 调岗但职级尚未生效时，仍按原职级执行。
2. 晋升结果自人事系统标记的生效日起适用，不追溯已完成的出差。
3. 临时担任项目负责人不自动提升职级或差旅等级。
4. 员工同时具有专业序列和管理序列时，须在出差申请中注明采用的生效序列。
5. 查询不到职级时，由 HRBP 在出差审批前确认，不得由员工自行推定。

## 5. 认定职责

| 角色 | 主要职责 |
|------|----------|
| 员工本人 | 核对出差申请中的身份、岗位和职级，不得手工提高等级 |
| 直属负责人 | 确认岗位名称、出差任务与成本中心真实有效 |
| HRBP | 处理兼岗、借调、晋升待生效和系统缺失等异常 |
| 行政管理中心 | 根据已确认职级匹配差旅政策，不负责修改职级 |
| 财务共享中心 | 报销时复核申请记录与费用标准是否一致 |

## 6. 常见人事变动

### 6.1 晋升与降级

行程开始前生效的职级调整，整段行程按新职级执行；行程开始后才生效的，整段行程仍按出发日职级执行，避免同一行程拆分标准。

### 6.2 调岗与借调

跨部门调岗以人事系统生效日期为准。仅变更汇报关系但未变更职级的，不影响差旅等级。借调人员仍使用原劳动关系所属公司的职级，由实际承担费用的成本中心审批。

### 6.3 返聘与短期聘用

退休返聘人员按返聘协议约定执行；协议未约定差旅标准时，由 HRBP 根据实际职责提出建议档位，最高不得超过 T3，并由部门负责人批准。

## 7. 认定所需证据

正常情况以人事系统快照为唯一依据。系统维护期间，可使用加盖电子签章的调岗通知、晋升通知或 HRBP 书面确认作为临时证据。名片、邮件签名、项目群昵称和口头称谓不能作为职级证据。

涉及外部顾问、派遣和外包人员时，还应核对合同中的费用承担方和差旅条款。合同只写“据实报销”而未约定标准的，仍须按本制度的默认等级执行。

## 8. 与差旅制度的关系

岗位职级不能直接确定机票、酒店或补助标准。取得 P 序列或 M 序列职级后，还需依据职级与差旅等级映射规则确定 T0 至 T4，再结合目的地城市类别和具体出差场景执行。

## 9. 示例

- “资深工程师”通常对应 P6，但应以人事系统为准。
- “研发经理”对应 M2；如果同时保留 P7 专业职级，可采用两者中较高对应档。
- 实习生即使承担“助理工程师”工作，也统一按 T0，不按 P3 计算。
- P5员工在出发次日晋升为P6，因为P5和P6均映射为T2，本次行程标准不变；即使跨档，也以出发日职级为准。
- 外部人员被项目组称为“首席顾问”，但合同未约定差旅标准时，仍按外部顾问默认规则处理，不能依据称谓认定为P8或P9。
