# 国内出差申请与审批权限规范

> 适用范围：中国大陆境内因公出差  
> 版本：v2.0 | 生效日期：2025-04-01  
> 归口部门：行政管理中心、财务共享中心

---

## 1. 申请时点

- 计划性出差应在出发前 **3个工作日**提交申请。
- 涉及机票、单笔费用超过10,000元或行程超过7天的，应提前 **5个工作日**提交。
- 未经批准不得预订不可退改的机票或酒店。

## 2. 申请必填信息

出差申请须包含人员身份、岗位职级、差旅等级、目的地、出差事由、起止日期、预计费用、成本中心和同行人员。跨多个城市时，应逐段填写交通和住宿预算。

预计费用应覆盖城际交通、住宿、市内交通、餐费补助、会议费及可能发生的退改费。尚不能确定具体价格时，应使用企业差旅平台近7日的可预订价格估算，不得以明显偏低预算规避更高层级审批。

## 3. 常规审批矩阵

| 条件 | 最低审批人 |
|------|------------|
| 1～3天且预计总费用不超过10,000元 | 直属负责人 |
| 4～7天，或预计总费用超过10,000元且不超过30,000元 | 部门负责人 |
| 超过7天，或预计总费用超过30,000元 | 事业部负责人 |
| 跨两个及以上成本中心 | 各成本中心负责人共同审批 |
| 使用专项项目预算 | 项目负责人和预算负责人共同审批 |

多个条件同时出现时，按审批层级最高的一项执行。

## 4. 特殊审批

下列情形除常规审批外，还须增加相应审批：

| 情形 | 增加审批人 |
|------|------------|
| 试用期员工出差 | 部门负责人 |
| 实习生单独出差 | 原则上禁止；确需出差须 HRBP 和部门负责人批准 |
| 超交通或住宿标准 | 财务负责人 |
| 客户承担部分或全部费用 | 合规负责人 |
| 临时升级差旅等级 | HRBP、财务负责人 |
| 前往自然灾害或公共卫生事件影响地区 | 行政安全负责人 |

审批人不得审批本人的出差申请。直属负责人同时是预算负责人时，可以合并业务和预算审批，但系统应保留两个审批角色。多人同行可以关联同一出差事项，但每名员工的身份、等级和费用预算须分别记录。

## 5. 行程变更

目的地、日期、出差人员或预计总费用变化超过原预算20%时，应重新审批。仅调整同城拜访顺序且不增加费用时，无需重提申请。

预算增加不超过20%但出现舱位升级、住宿超标或新增境外段时，仍需按相应专项规则审批。因客户临时取消而缩短行程的，应及时关闭未使用预订，避免产生可避免的损失。

## 6. 紧急出差

生产事故、重大客户故障或监管要求导致无法事前审批的，可由直属负责人通过企业即时通讯确认后先行出发，并在 **1个工作日内**补齐系统审批。未按时补批的费用进入人工复核，不当然报销。

## 7. 审批与费用标准的区别

审批通过只代表出差事项和预算获得授权，不代表所有实际消费都可以报销。交通、住宿和补助仍须根据差旅等级、城市类别和票据规则核验。

## 8. 各角色职责

| 角色 | 职责 |
|------|------|
| 出差人 | 如实填报行程、预算、等级和客户承担情况 |
| 直属负责人 | 判断出差必要性、人员安排和业务目标 |
| 部门/事业部负责人 | 审查长周期、高金额或特殊人员出差 |
| 预算负责人 | 确认成本中心余额和费用归属 |
| 行政管理中心 | 提供预订、城市分类和安全支持 |
| 财务共享中心 | 校验标准、票据、预支和报销 |

## 9. 申请关闭与归档

出差取消时，申请人应在1个工作日内关闭出差单并处理退订。返程后，出差单与报销单、退改记录和专项审批共同归档。只有审批但没有实际出行的，不得申领餐费补助或其他差旅费用。

## 10. 判断示例

- T2员工出差3天、预算8,500元，常规情况下最低由直属负责人审批；若其处于试用期，还须增加部门负责人审批。
- 两名员工出差5天、各自预算8,000元，应按各自申请判断时长条件，最低均由部门负责人审批。
- 原预算9,000元增加到10,500元，增幅超过20%，应重新审批；即使增幅较小，只要新增超标酒店也需专项审批。
