# 支付方式与资金安全规范

> 适用范围：买家支付、退款原路退回、商家收款账户安全  
> 版本：v2.5 | 生效日期：2025-02-15  
> 归口部门：支付中心 × 风险管理部

---

## 1. 支持的支付方式

| 方式 | 单笔限额（参考） | 说明 |
|------|------------------|------|
| 微信支付 | 按微信账户等级 | 支持分付/分期（以微信侧为准） |
| 支付宝 | 按支付宝账户等级 | 支持花呗分期 |
| 云闪付 / 银行卡 | 按发卡行 | 借记卡、信用卡 |
| 平台余额 | 账户可用余额 | 不可透支 |
| 礼品卡 / 购物卡 | 卡面余额 | 不找零、不兑现 |
| 对公转账 | 企业购授信额度内 | 须备注订单号，人工核销 |

**组合支付：** 余额/礼品卡可与第三方支付组合；优惠券抵扣优先于现金支付部分。

> 关联规则：优惠券叠加顺序参见《促销活动与优惠券使用规则》第 3 节“叠加优先级（结算顺序）”；积分抵扣限制参见《会员体系与积分权益说明》第 2.2 节“使用与有效期”。

## 2. 支付流程与超时

```
创建订单 → 调起收银台 → 支付成功回调 → 订单变为待发货
```

- **待付款超时：** 普通订单 **30 分钟**未支付自动关闭；大促可缩短为 **15 分钟**；
- **重复支付：** 系统识别同一订单多次成功扣款，**自动退回**多余款项（1~3 工作日）；
- **支付中状态：** 银行处理中超过 **2 小时**未终态，客服可协助查询，禁止引导用户重复下单支付。

## 3. 退款原路退回

| 原支付方式 | 退回路径 | 到账时效 |
|------------|----------|----------|
| 微信 / 支付宝 | 原账户 | 即时~24 小时 |
| 银行卡 | 原卡 | 1~3 工作日（节假日顺延） |
| 平台余额 | 余额账户 | 即时 |
| 礼品卡 | 原卡额度 | 即时（过期卡退回余额） |
| 组合支付 | 按支付比例拆分退回 | 取各通道较长时效 |

**部分退款：** 按商品行实付金额退，已用积分/券按促销与会员规则处理。

> 关联规则：优惠券分类参见《促销活动与优惠券使用规则》第 2 节“优惠券分类”；优惠券能否退回参见《促销活动与优惠券使用规则》第 6 节“客服常见问题应答”；积分退回规则参见《会员体系与积分权益说明》第 2.2 节“使用与有效期”。

## 4. 分期与免息

- 免息分期由 **品牌/商家/平台** 补贴手续费，商品页须标注期数与每期金额；
- 发生退款：已分期订单按 **剩余本金** 退回，已收利息/手续费是否退还以签约方规则为准并在页面公示；
- 禁止商家私下诱导买家「先全款再返现」规避分期审核。

## 5. 风控拦截场景

系统或人工可能触发支付/提现拦截：

| 场景 | 处理 |
|------|------|
| 异地异常登录后大额支付 | 短信/人脸二次验证 |
| 短时高频下单退款 | 限流、人工审核 |
| 涉嫌信用卡套现 | 拒绝支付或冻结订单 |
| 收款账户与主体不符 | 禁止结算直至更正 |
| 钓鱼链接诱导付款 | 阻断并安全提示 |

**误杀申诉：** 用户通过「支付安全申诉」提交材料，风控 **48 小时内**复核。

---

## 6. 账户与资金安全须知

- 平台 **不会**索要支付密码、短信验证码；
- 客服外呼须核验工号，涉及退款只走站内售后，**不引导私下转账**；
- 礼品卡购买实名，禁止黄牛囤卡倒卖；
- 商家结算账户变更须法人人脸 + 对公打款验证。

---

## 7. 对账与异常处理

- 支付成功但订单仍「待付款」：优先查回调延迟，客服可 **手动核销**（须支付流水号）；
- 退款失败（银行卡注销等）：退入 **平台余额** 或联系客服更换收款方式；
- 商户侧：支付手续费、通道费率以合同及结算单为准；结算单、差异申诉和提现流程参见《商家入驻结算与对账流程》第 4 节“对账与提现”。

## 8. 客服常见问题应答

| 问题 | 要点 |
|------|------|
| 扣款了订单没生成 | 查支付单号，重复扣款走自动退或人工退 |
| 退款退到哪里 | 原路退回，组合支付拆分说明 |
| 为什么支付被拒 | 可能风控，引导申诉或换支付方式 |
| 分期退了还有利息吗 | 按页面/资方规则，告知查账单 |

> 关联规则：售后审核及退款发起时限参见《售后服务与退换货政策》第 4 节“售后时效 SLA”；退款发起后的到账路径以本文件第 3 节“退款原路退回”为准。
