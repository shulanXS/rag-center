# 商品上架与类目合规规范

> 适用范围：POP 商家、自营采销、品牌旗舰店  
> 版本：v3.5 | 生效日期：2025-02-20  
> 归口部门：平台治理部 · 类目运营

---

## 1. 上架准入

商家须完成：

1. **企业/个体资质**审核（营业执照、法人身份证、对公账户）；
2. **类目授权**：品牌需提供商标注册证或授权链（二级以内）；
3. **保证金**：按类目缴纳 1000~50000 元不等，关店无纠纷可退。

**禁售清单（节选）：**

- 枪支弹药、管制刀具、毒品及制毒工具；
- 假币、发票、窃听窃照器材；
- 未取得批号的药品、医疗器械（除平台白名单）；
- 侵犯知识产权的仿品；
- 活体动物（除合规宠物类目）。

---

## 2. 商品信息要求

### 2.1 标题规范

- 长度：25~60 字符（中文按字计）；
- 结构：品牌 + 产品名 + 核心规格 + 适用场景；
- 禁止：堆砌关键词、夸大宣传（「全国第一」「最好」等绝对化用语）、与实物无关热词。

### 2.2 主图与详情

| 要求 | 说明 |
|------|------|
| 主图 | 800×800 以上，白底或场景图，**不得水印、牛皮癣** |
| 详情 | 须展示真实商品，**禁止盗图** |
| 对比图 | 须有数据来源，不得贬低竞品 |
| 功效宣称 | 化妆品/保健品类须符合广告法及行业备案 |

### 2.3 价格与库存

- **标价**为真实销售价格，不得先涨后降营造虚假优惠；
- 库存为 0 自动下架，**不得**故意标低价引流后拒发（低价引流违规）。

---

## 3. 类目资质对照（示例）

| 类目 | 必备资质 |
|------|----------|
| 食品 | SC 编号、生产许可证、质检报告 |
| 3C 数码 | CCC 认证（目录内产品） |
| 化妆品 | 备案/注册凭证、成分表 |
| 婴幼儿配方乳粉 | 配方注册证书 |
| 出版物 | ISBN、出版许可证 |

资质到期前 **30 天**系统提醒，过期 **自动下架** 相关 SKU。

---

## 4. 审核流程

```
商家提交 → 机审（违禁词、图片 OCR）→ 人审（类目、资质）→ 上架 / 驳回
```

- 普通类目：**24 小时**内完成；
- 敏感类目（医疗、金融）：**72 小时**；
- 驳回须给出 **可修改的具体原因**，商家修改后可重新提交。

---

## 5. 抽检与下架

平台每月 **随机抽检 5%** 在售 SKU：

- 实物与页面不符：限期整改，严重者下架并扣保证金；
- 质检不合格：立即下架，通知买家退货退款；
- 重复违规：**清退店铺**。

---

## 6. 自营与 POP 差异

| 项 | 自营 | POP |
|----|------|-----|
| 定价权 | 采销定价 | 商家定价（平台可活动锁价） |
| 发货 | 平台仓 | 商家仓或平台云仓 |
| 客服 | 平台首接 | 商家主责，平台可介入 |
