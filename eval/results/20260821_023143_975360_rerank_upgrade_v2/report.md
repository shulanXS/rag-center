# v2索引下LLM重排与Qwen3-Rerank精排对比实验报告

## 结论

**综合评估建议采用Qwen3精排。**

在 golden_basic_20_v2 的 20 道题上，Context Precision 从 0.943 变为 0.892，变化 -5.1 个百分点；Context Recall 从 0.950 变为 0.983，变化 +3.3 个百分点；P95 延迟变化 -76404.4 ms（-95.9%）；平均应用模型调用数变化 +0.00 次。本次20题评测中，Qwen3精排的Context Precision较LLM重排低5.1个百分点，但较v2不重排基线仍提升0.4个百分点；当前样本量较小，且尚未覆盖完善的回归题集，不能仅凭这次小样本差异否定精排。与此同时，Qwen3将P95延迟从79.7秒降至3.3秒，降低95.9%，并避免把生成式LLM的长耗时放入每次检索。历史同项目专项测算中，Qwen3每1000次约0.97元，LLM重排约17.04元，Qwen3理论成本低约94.3%；该成本数据用于选型参考，不作为本轮精确账单。综合质量、延迟、稳定性和规模化成本，建议中台默认采用Qwen3精排，LLM重排保留为离线质量参照或低频高价值场景的可选能力。

## 实验目标

- 验证能力：rerank_upgrade_v2
- baseline：v2 + 原有 LLM 重排
- candidate：v2 + Qwen3-Rerank 精排
- 唯一允许变化的字段：`rerank_provider`

## 数据与运行条件

- 数据集：`golden_basic_20_v2`
- suite：`basic`
- 题目数量：20 道
- 每道题每组正式执行 1 次
- 索引版本：baseline=v2，candidate=v2
- RAGAS 遥测关闭，离线 Langfuse 关闭
- 每道题只生成一份共同 RRF Top20 候选
- A、B 两组分别精排并最终返回 Top10
- Query Rewrite、同义词扩展和证据编排全部关闭

## 综合选型依据

### 质量

| 链路 | Context Precision | 相对v2不重排 |
|------|------------------:|-------------:|
| v2不重排 | 0.889 | — |
| v2 + LLM重排 | 0.943 | +5.4 个百分点 |
| v2 + Qwen3精排 | 0.892 | +0.4 个百分点 |

Qwen3较LLM重排低5.1个百分点，但并未使v2不重排基线退化。本轮只有20道题，尚未形成覆盖完善的回归题集；Recall差异又集中在一道人为边界题，因此当前质量差距应继续观察，不宜单独决定中台选型。

### 延迟与稳定性

- LLM重排P95：79.7秒；Qwen3精排P95：3.3秒。
- Qwen3减少76.4秒，降幅95.9%。
- LLM重排正式运行中有2道题首次超时；Qwen3共20道全部一次成功。
- 对在线RAG中台而言，约80秒的排序延迟不适合作为默认检索链路。

### 调用成本

历史同项目专项测算结果如下：

| 项目 | LLM重排 | Qwen3精排 |
|------|--------:|----------:|
| 单次平均理论成本 | ¥0.01704 | ¥0.000969 |
| 每1000次预计成本 | ¥17.04 | ¥0.97 |

Qwen3理论成本约低94.3%，约为LLM重排的1/17.6。以上使用历史实验的模型、候选数量和价格快照，仅作为量级参考；本轮正式运行尚未持久化逐次Token，不能把该数据视为当前账单。

### 综合结论

**建议RAG中台默认采用Qwen3精排。**

LLM重排在20题上取得更高Context Precision，但其延迟、超时风险和规模化成本明显更高。Qwen3已经较v2不重排基线带来小幅Precision收益，同时拥有数量级更优的速度和成本，更适合作为在线默认能力。LLM重排可保留为离线质量参照，或用于少量高价值、允许长时间等待的查询。
